# Portafolio Web Personal - Oswaldo Danilo Angulo Tamayo

Este proyecto es el portafolio web personal e interactivo de Oswaldo Danilo Angulo Tamayo, desarrollado como parte del 8vo semestre de la carrera de Ingeniería de Software. El objetivo es presentar de forma profesional su perfil, habilidades técnicas y proyectos de GitHub.

## Tecnologías Utilizadas

- **HTML5 Semántico:** Estructura web accesible y optimizada (SEO).
- **CSS3 Vanilla & Custom Properties:** Arquitectura limpia utilizando variables en CSS (`:root`) para mantener un Design System consistente (colores, tipografía, espaciados) sin usar frameworks externos.
- **JavaScript (Vanilla JS):** Lógica y manejo del DOM para interactividad, sin librerías de terceros.

## Características Principales

1. **Arquitectura Limpia en CSS:** Separación de Design Tokens, reset, tipografía y utilidades globales.
2. **Design System Propio:** Documentación visual en la página independiente `design-system.html` donde se muestran los componentes y la paleta de colores.
3. **Responsive Design (Mobile-First):** Interfaz fluida adaptable a celulares, tablets y monitores usando Flexbox y CSS Grid.
4. **Interactividad Dinámica:**
   - Cambio de tema Claro / Oscuro.
   - Menú de navegación móvil responsivo (Hamburguesa).
   - Filtro interactivo de proyectos por tecnología (Python, TypeScript, etc.).
5. **Secciones Informativas:** Inicio (Hero), Sobre Mí, Habilidades (Skills), Proyectos Destacados y Contacto.

## Historial de Desarrollo (Esquema de 7 Commits)

El proyecto fue desarrollado de manera estructurada en 7 etapas (commits) iterativas:

1. **Commit 1:** Estructura HTML Base (HTML5 semántico).
2. **Commit 2:** Arquitectura CSS y Variables (Design System).
3. **Commit 3:** Página del Design System y maquetación de componentes.
4. **Commit 4:** Maquetación de Secciones de Presentación (Inicio, Sobre mí, Habilidades).
5. **Commit 5:** Maquetación de Proyectos y Formulario de Contacto.
6. **Commit 6:** Lógica e interactividad en JavaScript.
7. **Commit 7:** Pulido responsivo final, revisiones de accesibilidad y despliegue.

## Cómo ejecutar localmente

No requiere instalación de dependencias, Node.js ni empaquetadores.
Simplemente descarga el repositorio y abre el archivo `index.html` en cualquier navegador web moderno.
