Design System

Las decisiones visuales del portafolio están centralizadas en CSS Custom Properties declaradas en :root. Cada componente de esta página es exactamente el mismo que se usa en el sitio: comparten clases y tokens, no son copias.

Volver al portafolio

1. Colores

La paleta se define una sola vez y se reutiliza mediante variables. Al activar el tema oscuro con el botón de la barra superior, los mismos tokens cambian de valor y toda la página se adapta sin duplicar reglas.

Colores de marca

  • Primary --color-primary claro: #2563eb oscuro: #60a5fa
  • Secondary --color-secondary claro: #7c3aed oscuro: #a78bfa
  • Accent --color-accent claro: #0d9488 oscuro: #2dd4bf
  • Gradiente de marca --gradient-brand primary → secondary

Superficies

  • Background --color-background claro: #ffffff oscuro: #0b1120
  • Surface --color-surface claro: #f8fafc oscuro: #111a2e
  • Surface alt --color-surface-alt claro: #f1f5f9 oscuro: #18233d
  • Border --color-border claro: #e2e8f0 oscuro: #1e2c48

Texto y estados

  • Text --color-text claro: #0f172a oscuro: #e2e8f0
  • Text muted --color-text-muted claro: #64748b oscuro: #94a3b8
  • Success --color-success #16a34a
  • Warning --color-warning #d97706
  • Danger --color-danger #dc2626

Colores de iconos

Los iconos de las categorías de Habilidades y de las tarjetas de Contacto usan un color propio definido en un token. El icono toma ese color y el fondo se genera con color-mix() al 14 %, así que un solo token controla las dos capas. Los logotipos de cada skill no usan estos tokens porque vienen de Devicon con su color original.

  • Frontend Título de categoría en Habilidades --color-tech-html #e34f26
  • Backend Título de categoría en Habilidades --color-tech-django claro: #0c9d58 oscuro: #22c07a
  • Bases de datos Título de categoría en Habilidades --color-tech-postgres claro: #336791 oscuro: #7aa8d8
  • Datos e IA Título de categoría en Habilidades --color-tech-pandas #8b5cf6
  • Herramientas Título de categoría en Habilidades --color-tech-colab #e8a400
  • Correo Tarjeta de contacto --color-tech-mail #ea4335
  • GitHub Tarjeta de contacto --color-tech-github claro: #24292e oscuro: #f0f6fc
  • LinkedIn Tarjeta de contacto --color-tech-linkedin claro: #0a66c2 oscuro: #4a9de8
  • Ubicación Tarjeta de contacto --color-tech-place #ef4444

Declaración en código

:root {
  --color-primary: #2563eb;
  --color-secondary: #7c3aed;
  --color-background: #ffffff;
  --color-surface: #f8fafc;
  --color-text: #0f172a;
  --color-text-muted: #64748b;
  --color-tech-django: #0c9d58;
}

.icon--backend { --icon-color: var(--color-tech-django); }

[data-theme="dark"] {
  --color-background: #0b1120;
  --color-surface: #111a2e;
  --color-text: #e2e8f0;
}

2. Tipografía

Una sola familia tipográfica (--font-primary) para todo el contenido y una monoespaciada (--font-mono) para código y tokens. Los tamaños salen de una escala fija; el h1 usa clamp() para adaptarse al ancho de pantalla.

h1 · --text-4xl · clamp(2.25rem, 6vw, 3.5rem) · 700

Encabezado principal

h2 · --text-3xl · 2.25rem · 700

Título de sección

h3 · --text-xl · 1.375rem · 700

Subtítulo de bloque

p · --text-base · 1rem · line-height 1.65

Párrafo estándar del sitio. La medida de línea está limitada a 68ch mediante la variable --measure para que el texto siga siendo cómodo de leer incluso en pantallas anchas.

.text-muted · --text-base · --color-text-muted

Texto secundario, usado para descripciones de apoyo y metadatos.

a · color --color-primary · hover --color-secondary

3. Espaciado

Escala basada en múltiplos de 4 px expresada en rem. Todos los márgenes, rellenos y separaciones del sitio usan alguno de estos siete valores.

  • --space-2xs0.25rem
  • --space-xs0.5rem
  • --space-sm0.75rem
  • --space-md1rem
  • --space-lg2rem
  • --space-xl3rem
  • --space-2xl5rem

4. Bordes, radios y sombras

Tres niveles de redondeo más una variante circular, y tres niveles de elevación que distinguen contenido plano, tarjetas y capas flotantes como el modal.

Border radius

  • --radius-sm · 0.5rem
  • --radius-md · 1rem
  • --radius-lg · 1.5rem
  • --radius-full · 999px

Sombras

  • --shadow-sm
  • --shadow-card
  • --shadow-lg
